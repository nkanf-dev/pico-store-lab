## Android 下载与安装修复

- 修复部分头显下载到 100% 后误报“包名或版本不匹配”的问题。
- 原版应用的安装和更新不再依赖账号适配检查；适配检查不可用时仍可安装原版。
- 区分下载不完整、安装包无法读取和实际版本不一致的提示。

在 Lab 设置中检查更新，或下载 `pico-store-android.apk` 覆盖安装。无需卸载现有版本。

本次主要修复 Android 客户端，桌面端的使用方式不变。

## Android download and installation fixes

- Fix downloads incorrectly reporting a package or version mismatch at 100% on some headsets.
- Keep original app installs and updates working independently of sign-in adaptation checks.
- Distinguish incomplete downloads, unreadable APKs, and actual version mismatches.

Check for updates in Lab settings, or install `pico-store-android.apk` over the current version. No uninstall is needed.

This release focuses on Android fixes. Desktop usage is unchanged.
